# Janhavi's Digital Canvas

Create a premium, modern, visually stunning and fully responsive personal portfolio website for Janhavi Girase, an aspiring Web Developer and AI/ML enthusiast. The website should use a clean dark futuristic theme with subtle glassmorphism, smooth animations, elegant typography, soft gradients and minimal neon accents while keeping the overall design professional and sophisticated. The hero section should introduce Janhavi with a strong headline such as “Building Modern Web Experiences with Code, AI & Data”, a short professional introduction, profile image area, and clear View Projects and Contact Me buttons. Include essential sections for About Me, Skills, Projects, Interests, Experience/Certifications, and Contact. Showcase skills including Python, HTML, CSS, Node.js, SQL, Docker, Supabase, databases, backend development and modern web technologies. Highlight her interests in Artificial Intelligence, Machine Learning, Data Analysis, Content Creation and Digital Marketing, showing her combination of technical, analytical and creative abilities. Add a Projects section with 3–4 project cards containing the project title, short description, technologies used, GitHub link and Live Demo button. Include subtle scroll animations, hover effects, responsive navigation, social links, downloadable resume button, professional footer and a functional contact section. Build the portfolio using React/Next.js, TypeScript and Tailwind CSS with clean reusable components, responsive design, accessibility, SEO-friendly structure and excellent performance. The final website should feel like a high-end professional developer portfolio suitable for internships, freelance opportunities and future software/AI roles, while maintaining a personal, confident and authentic identity for Janhavi Girase.
